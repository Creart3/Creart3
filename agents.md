# Proyecto: Juego de imitar poses de obras de arte

## Descripción
App web interactiva. La pantalla se divide en dos: a la izquierda la imagen de una obra
de arte (con su nombre debajo) y a la derecha la cámara del usuario. El usuario debe
imitar la pose de la obra. Cuando la logra, el recuadro de la cámara pasa de rojo a verde,
se muestra una señal positiva y avanza automáticamente a la siguiente obra.
Al completar 5 obras aparece un meme para imitar, y luego el ciclo se repite.

## Stack y restricciones
- p5.js y ml5.js (ml5 v1, que usa ml5.bodyPose / ml5.handPose). Versiones fijas por CDN.
- Solo HTML, CSS y JavaScript.
- Debe funcionar como sitio estático (se publicará en GitHub Pages): rutas relativas.
- Código en español para comentarios y nombres de variables descriptivos.
